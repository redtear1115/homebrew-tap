# Security policy

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository.
Don't open a public issue for security problems.

## Scope

This repository covers the Homebrew formula, the bottles published from it, and this
repository's workflows.

Vulnerabilities in the `marsdawn` CLI itself belong to its own repository: report them at
https://github.com/redtear1115/mars-dawn-kit/security.

Published tags are never moved.
